# Périmètre du site

Ce dépôt est réservé au site. Le bot actif sur le PC Linux est un projet séparé.

Le site conserve le design, les dossiers, les machines, les véhicules, les
statistiques, les profils et les panneaux d’accès.
Les essais sur GitHub Pages restent locaux au navigateur.

Aucun programme du bot ni mécanisme de synchronisation de ses données n’est
inclus. Un éventuel futur raccordement devra être défini et validé séparément.

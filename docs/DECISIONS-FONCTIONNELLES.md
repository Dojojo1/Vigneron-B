# Périmètre du site

Ce dépôt est réservé au site. Le bot actif sur le PC Linux est un projet séparé.

Le site conserve le design, les dossiers, les machines, les véhicules, les
statistiques, les profils et les panneaux d’accès.
Les essais en mode aperçu restent locaux au navigateur. L'accueil GitHub Pages
ouvre la connexion sur le backend Python pour les vrais comptes et données partagées.

Le programme du bot reste dans son projet séparé. Le site contient le transport
signé et la projection des Machines confirmées. Le bot existant exécute les
demandes et conserve les rappels sur Discord. Les blanchiments et véhicules ne
sont pas encore raccordés par ce transport.
